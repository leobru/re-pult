# ВЫЗОВЛ: запуск ЛИСПа из архива ПУЛЬТа

Исходник: [pascal/vyzovl.pas](../pascal/vyzovl.pas).
Образ — **2148:01074**, совпадает с **2248:01074**; дата **03.07.86**.
Каталог скрывает его под именем РЕЗРВ3. Программа занимает **294 слова**,
адреса **00000–00445**. Начало глобального кадра/конец образа — **00446**.
Адреса и машинные значения ниже восьмеричные, количества слов десятичные.

## Работа программы

1. Копирует 14 слов текущей командной строки НАБЛ из **57640** в **70000**.
   Временно изменяет входной обмен АДСИС, затем делает RESET стандартного
   INPUT. Первое имя пропускает как имя самого приказа, второе считает
   именем исходного файла. Имя имеет до шести букв/цифр и начинается буквой.
2. Читает текущий каталог архива с барабана **27:036** в **64000**,
   получает описание архива из **57776**. Первая литера названия каталога
   должна принадлежать диапазону **040–0114**.
3. Ищет имя среди пар «имя, дескриптор» каталога. При нахождении выделяет
   из дескриптора начальную зону и длину, прибавляет архивное смещение
   и подключает зоны к INPUT. В исходнике `memory := nil` обозначает
   реальный адрес **64000**, соответствующий машинному представлению NIL.
4. Переписывает текст до **0172** на барабан **10**, заменяя **0175**
   пробелами. Дописывает конец текста, конец строки и шесть пробелов,
   сбрасывает OUTPUT и восстанавливает его обычную барабанную настройку.
5. Читает **66:1653 → лист 2**, проверяет **05252** на **`NONE  `**.
   При несовпадении печатает **«ИСПОРЧЕН ЛИСП-ТРАНСЛЯТОР»** и возвращается.
6. Читает **66:1652 → лист 1**, **1654 → лист 3**, **1655 → лист 4**.
   В **70003** помещает дескриптор **66:1651 → лист 0**.
   Код в **70000** выполняет этот обмен; **70001** устанавливает
   **М16 = 70002** и передаёт управление в **00410** загруженного ЛИСПа.
7. Настраивает перехват Э74 через ASCII **`KEYE72`**, устанавливает
   обработчик в **70010–70011**. Он печатает **`<*> ФИНАЛ <*>`** через
   СБОЙ **76005** и возвращается в ПУЛЬТ через **76002**.
   Перед запуском выводятся **«РАБОТАЕТ ЛИСП-ТРАНСЛЯТОР»** и две строки.

Слово параметров **70002 = `0020001000031000`** сохранено без изменения;
его использование внутри отсутствующего комплекса ЛИСПа здесь не разобрано.
Связь требуемого пятизонного комплекса с фрагментами
[2148:01012](lisp-1012.md) не установлена.

## Компоновка и исходный текст

| Участок | Начало | Следующая граница | Слов |
|---|---|---|---:|
| Заголовок | 00000 | 00011 | 9 |
| Литералы | 00011 | 00102 | 57 |
| SkipSpaces | 00102 | 00110 | 6 |
| ReadName | 00110 | 00157 | 39 |
| GetArchive | 00157 | 00200 | 17 |
| BindInput | 00200 | 00212 | 10 |
| BindOutput | 00212 | 00225 | 11 |
| FlushOutput | 00225 | 00237 | 10 |
| Главная программа | 00237 | 00417 | 112 |
| Возврат и встроенные шаблоны | 00417 | 00435 | 14 |
| Общий пролог процедур | 00435 | 00441 | 4 |
| Инициализатор программы | 00441 | 00446 | 5 |

Глобальные поля через М1: **012** buffer, **013** linebuf,
**014** name, **015** archive, **016** index, **017** info,
**020** address, **021** zones, **022** memory.

Разбор имени, поиск файла, выделение полей SEL, цикл копирования и
диагностики восстановлены операторами Паскаля. CODE сохраняет обращения
к физической памяти, обмены, старые входы АДСИС, упаковку ALFA,
перехват экстракода и замену выполняемых страниц. Копирование каталожного
дескриптора через CODE передаёт те же 48 бит из ALFA в INTEGER.
Константы объявлены в порядке оригинального массива.

Недостижимый возврат **00417** сохранён: он присутствует в образе перед
встроенными данными. Внутри CODE значимы разделители `=`/`,`:
они задают упаковку полуслов, включая переходы между CODE и Паскалем.

## Перекомпиляция и проверка

```sh
make checkvyzovl
```

Проверка использует исторические компиляторы Паскаля-автокода 9
**17.05.88** с 2248 и **09.12.88** с проверенным ремонтом из сборщика 2068.
Дата компиляции фиксируется как **03.07.86** через `localtime()`.
Исходные диски сохраняются; компиляция и запуски идут на частных копиях.
Полученные машинные слова не исправляются после компиляции.

**При обоих компиляторах совпадают:** заголовок, все 57 слов литералов,
все шесть процедур, глобальные смещения, главная программа,
встроенные шаблоны и общий пролог. Начала и размеры всех участков
сохранены. Имеются ровно два различающихся слова в автоматически
генерируемом инициализаторе:

| Адрес | Оригинал | Рекомпиляция | Различие |
|---|---|---|---|
| 00443 | `0444001367174027` | `0444001367174251` | ПВ через М15: **74027 → 74251**, RESET INPUT |
| 00445 | `6044001603074032` | `6044001603074313` | ПБ: **74032 → 74313**, REWRITE OUTPUT |

В используемой АДСИС **74027** содержит переход в **74251**, а **74032** —
в **74313**. Короткие входы оригинала и прямые адреса перекомпиляции
обращаются к одним реализациям. Полного побитового совпадения программы
из 294 слов поэтому не заявляется; совпадают **292 слова**.
За границей программы остаются 730 слов зонного остатка; пять из них
отличаются при перекомпиляции. Исходник не задаёт этот остаток.

`tests/vyzovl.py` проверяет точные значения обоих допустимых различий
и отклоняет любые дополнительные. `--exact` дополнительно требует
полной тождественности и обнаруживает эти два слова.
Отчёты и пара листингов для сравнения:

* `build/vyzovl-rebuild/{original,generated}.lst`;
* `build/vyzovl-rebuild/comparison.json`;
* аналогичные файлы в `build/vyzovl-rebuild-december/`.

Для каждого компилятора оригинал и перекомпилированный вариант
сравнены на четырёх сценариях: отсутствующее имя файла,
отсутствующая настройка архива, имя вне каталога, копирование
короткого текста с последующим отказом проверки сигнатуры ЛИСПа.
Терминальная выдача совпала, все запуски вернулись в командный цикл
и завершились приказом КОНЕЦ без АВОСТ.

В пробах используется временная подстановка в слот **ЛЕС, 055–057**
на частном 2068: его обычный Pascal-загрузчик готовит внешний кадр,
необходимый для EXIT. Команда `лес` в этих тестах — технический псевдоним.
Историческое имя вызова ВЫЗОВЛ этим не устанавливается.
Устройство 66 в последнем сценарии подключено к частному тестовому
тому с нулевой сигнатурой; полноценный транслятор ЛИСПа не запускался.
