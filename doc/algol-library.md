# Стандартная библиотека БЭСМ-АЛГОЛ: поиск по `_БИБ`

На томах **2148 и 2248 библиотека одинакова**: побайтно совпадают все
35 зон **0320–0362**, включая каталог и тексты алгоритмов. В каталоге
**182 имени**. Это библиотека транслятора БЭСМ-АЛГОЛ, вызываемого командой
`АЛГ`.

Все адреса, зоны и значения полей ниже восьмеричные; количество имён
и количество зон в предыдущем абзаце десятичные.

## Откуда читается библиотека

В задании `pult2068.b6` первым подключён том `2248` на устройстве 57,
с картой `физо мб21`. Драйвер АЛГ перед запуском транслятора устанавливает
смещение этого устройства в **0300**. Поэтому физический барабан 21,
дорожка T, соответствует зоне **0300 + T** подключённого системного тома.
Замена 2248 на 2148 на том же устройстве сохраняет эту схему.

На первом `_БИБ` код первого прохода транслятора выполняет:

| Адрес исполнения | Действие |
|---|---|
| 01243–01244 | Проверяет флаг 03020; при первом обращении устанавливает его |
| 01245 | `Э70 01254`, слово обмена `0014020000210020`: физический барабан 21, дорожка 020 → страница 2, адрес 04000 |
| 01246 | `Э70 01255`, слово обмена `0014030000210021`: физический барабан 21, дорожка 021 → страница 3, адрес 06000 |
| 01251 | Устанавливает режим библиотечного поиска в 03022, возвращается к разбору текста на 01020 |

Таким образом, начальный блок библиотеки читается из **зон 0320–0321**
системного тома на устройстве 57. Собственно каталог целиком помещается
в зоне **0320**, слова 0000–0752; зона 0321 уже содержит начало текстов
алгоритмов (первый текст имеет смещение 02000 слов).
Сам `_БИБ` не выбирает том по его номеру и не выполняет
поиск в архиве ПУЛЬТа: в этом пути используются постоянные слова
физического обмена. Адреса кода приведены после переноса первого прохода
из зоны 0300: первоначально она читается в страницу 1, затем её рабочая
часть переносится в страницу 0 (02035–02037).

## Как ищется имя

1. **01050–01060** собирает имя в последовательность шестибайтных слов
   ГОСТ в буфере 03000. Неполное последнее слово дополняется байтами 0176;
   старший бит последнего слова устанавливается как признак конца имени.
2. **01063–01065** извлекает первый код имени и вычитает 033.
   Это индекс начального указателя в таблице при 04000.
3. **01066–01067** извлекает указатель маской 07777. Нулевой указатель
   означает отсутствие имени.
4. **01071–01075** сравнивает все слова имени с каталогом. При несовпадении
   берёт ссылку из дескриптора текущей записи и продолжает цепочку.
   Сравнение полное, включая признак последнего слова.
5. **01124–01131** добавляет найденную запись в список выбранных алгоритмов,
   исключая повторное включение. **01103–01117** обрабатывает указатели
   зависимостей, записанные в каталоге.
6. **01133–01156** извлекает адреса текстов алгоритмов из дескрипторов;
   **01166–01215** читает их в страницу 23 и передаёт байты в обработку
   исходного текста. Текст алгоритма включается при трансляции.
7. При исчерпании цепочки **01443–01453** формирует и печатает
   `В БИБЛИОТЕКЕ НЕТ АЛГОРИММА С ИМЕНЕМ …`.

Например, для `IN` первая буква имеет код 0102. После вычитания 033
получается индекс **047**. Цепочка каталога:

```text
0500 INVERT2 → 0503 INVERT1 → 0506 INVERT →
0510 I0 → 0512 I1 → 0514 INTERMS → 0
```

Ни `IN`, ни `INTEL` в ней нет.

## Формат каталога

Смещения здесь относительно начала зоны 0320, загруженного в 04000:

| Слово | Значение | Наблюдаемая роль |
|---:|---:|---|
| 0000 | 0 | Служебное поле |
| 0001 | 0752 | Последнее занятое слово каталога; это слово имени НОВ |
| 0002 | 01777 | Последнее возможное смещение внутри первой зоны, содержащей каталог |
| 0003 | 0104750 | Верхняя граница библиотечного содержимого в словах |
| 0004 | 0127777 | Служебное поле; точное назначение не установлено |
| 0005–0062 | Указатели или 0 | Начала цепочек имён по первому коду ГОСТ минус 033 |
| 0063–0752 | Записи, имена и списки зависимостей | Порядок записей в памяти не обязательно совпадает с порядком в цепочках |

Запись начинается с одного слова-дескриптора, за которым идут слова имени.
Дескриптор разбирается так:

```text
старший бит                 = установлен в имеющихся записях
биты 47–25, без старшего     = смещение текста алгоритма от начала библиотеки
биты 24–13                  = указатель списка зависимостей или 0
биты 12–1                   = указатель следующей записи цепочки или 0
```

Список зависимостей содержит по четыре 12-битных указателя на записи в
слове, начиная со старших разрядов; нулевой указатель завершает список.
Имена имеют по шесть байтов ГОСТ на слово; старший бит **последнего слова**
является признаком конца и не относится к первому символу этого слова.
Байты 0176 в конце имени — заполнение.

Адрес текста — **смещение в словах**. Для смещения S:

```text
зона тома = 0320 + S div 02000
слово     = S mod 02000
```

Загрузка вычисляет номер блока из S на 01167–01170 и прибавляет его к
постоянной 01236 = `0014230000217760` (01174–01175). Э70 на 01177 читает
страницу 23. Младшие пять разрядов поля дорожки дают её физический номер;
переход к следующему физическому барабану учитывается переносом в поле
устройства. Поэтому длинная библиотека продолжается за дорожкой 037
барабана 21.

## Формат текстов алгоритмов

Тексты содержат по шесть байтов ГОСТ в слове, от старших разрядов к
младшим. Старший бит каждого байта дополняет код до нечётности.
Ключевые слова записаны полностью с подчёркиванием; встречаются вставки
исходного автокода `_DOWN … _UP`. При включении через `_БИБ` этот текст
поступает в транслятор. Нулевые байты заполнения пропускаются; первое
нулевое слово завершает алгоритм (01202 → 01676).

Каталог содержит и записи с повреждённым текстом. Например,
[УППBULLM20](upp-bullm20.md) при смещении 061620 имеет 112 повреждённых
начальных слов; подключение обнаруживает ошибки чётности. Сохранившиеся
2010 слов позволяют разобрать обработку карточного пакета.

Для извлечения текста и исходных байтов:

```sh
python3 tools/algolcatalog.py 2248 --extract ERF --output build/erf.alg
```

## Проверка загрузки ERF

Программа, сохранённая через `сис алг` и `з …=тт`:

```text
_БИБ : ERF;
_begin output(`Щ',`z4d',ERF(0)); _end
```

При терминальном вводе исходного текста после `_end` требуется пробел,
затем обычное завершение файла `//` и ETX, как в [описании АЛГ](algol.md).

По трассе поиска сначала проверяется запись 0137 (`EILER1STEP`), затем
находится **0142 (`ERF`)**, дескриптор `4001072700000144`.
Из него извлекается смещение **010727**, то есть зона **0324**, слово **0727**.
Э70 на **01177** получает слово обмена `0014230000217764`, читает
физическую дорожку 024 барабана 21 в страницу 23. Исполнение программы
печатает **0** на терминал и возвращается в ПУЛЬТ без АВОСТ.

## Служебные процедуры

Назначение следующих групп установлено по извлечённым текстам и их
комментариям:

| Имена в каталоге | Назначение |
|---|---|
| TEXTINPUT, SYMBINPUT | Ввод последовательности символов в массив и чтение очередного символа входного потока |
| TEXTPRINT | Печать кодов ГОСТ из массива |
| TEXTPUNCH, NUMBPUNCH | Перфорация текста и чисел |
| TEXT, LENGTH | Перевод строки в массив кодов ГОСТ; определение длины строки |
| PACK, UNPACK | Упаковка и распаковка по шесть восьмибитных значений в слове |
| READ, WRITE | Обмен массивами с внешней памятью |
| READМЛ, WRITEМЛ | Обмен с проверкой выделенного диапазона зон |
| DSNAME, GET, PUT, CLOSOP, REMARK | Разбор имён, чтение и запись наборов данных, открытие и закрытие библиотек по паролю, диагностика архива библиотек данных |
| NEW, НОВ | Группы процедур обращения к системе БАНДИТ: создание и открытие базы, чтение и запись, удаление, каталог |
| SEGMENT, SEGMENTATION | Подготовка сегментированных программ и управление сегментами |
| MULCOM1, MULC1, MULCOM2, MULCOM3, WORD, ALCOM | Обработка управляющих карт, чтение слов входного потока, подготовка программы и данных, передача управления Алголу |
| УППBULLM20 | Преобразование перфокарт в кодировках УПП, BULL и М-20 к УПП для подачи компилятору |
| QUICKERSORT | Сортировка массива по возрастанию |

Тексты NEW и НОВ содержат сразу несколько объявлений процедур. У NEW
видны OPEN, ID, PUT, GET, DELETE, КТЛ и служебные подпрограммы. У НОВ
дополнительно есть PUTMOD, MOD, FINDFIRST, FINDLAST, FINDNEXT, FINDPRED,
FINDN, GETCUR, DELCUR и обработчики ошибок ON, IGNOR, REVISE.
В этих текстах непосредственно проверяется имя `БАНДИТ` и вызывается
код при 072000. У отдельно каталогизированной GET параметры `(DSN,A)`;
у GET в группе БАНДИТ параметры `(ИД,ИМ1)`.
Подробный [разбор NEW/НОВ](algol-new.md) описывает поля интерфейса,
представление имён, обработчики ошибок и проверенную несовместимость
входа с сохранившимся БАНДИТ. Для подключения НОВ требуется явно добавить
UR в `_БИБ`.

TEXTINPUT и SYMBINPUT используют входной поток задачи; работа с терминалом
для них не проверена. Классификация здесь основана на статическом чтении
исходного текста.
