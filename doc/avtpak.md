# АВТПАК: старый вызов автокода ИТМ и исполнитель цепочек приказов

АВТПАК занимает одну зону **01047** на томах 2148 и 2248, зону **047**
на восстановленном томе 2068. В [историческом каталоге](PULT.md#pdf-008)
он назван модулем приказов **АВТ, ПАКЕТ**. Код подтверждает оба назначения:
АВТ готовит текст для четырёхзонного транслятора автокода ИТМ, ПАКЕТ
подменяет ввод НАБЛ последовательностью заранее сохранённых приказов.

Это сохранившийся модуль прежней версии системы. Его загрузчик ожидает
**АВТТРН в зонах 071–074** устройства 40. Именно такой четырёхзонный файл
есть в каталоге руководства; на исследуемых томах эти зоны уже заняты
другими файлами. АВТ и ПАКЕТ отсутствуют в текущих таблицах приказов
НАБЛ, ПУСК и БАВТ. Наличие пятизонного автокода ИТМ в зонах 0400–0404
согласуется с переходом на новую версию транслятора, переиспользованием
старых зон и удалением приказов при сохранении самого АВТПАК. Точную
дату и последовательность этих изменений образ модуля не устанавливает.

Все адреса, коды, зоны и номера устройств далее восьмеричные. Номера
томов, размеры в словах и число элементов — десятичные. Отдельные
48-битные маски и шаблоны дополнительно представлены шестнадцатерично.

## Образы и листинги

SHA-256 шестибайтных образов:

| Том | SHA-256 |
|---|---|
| 2148 | `c8d8862d0403f8f36b5f2c94d02fca87e50625fcdcf1796323e5a246bac3d1e9` |
| 2248 | `f5ae4e1227934c9960b13b063925a9c2fa584328024d8b8475ac05d0f1eb135c` |

Единственное различие — байт окончания архивной диагностики в слове
**1375** образа; оно разобрано в [COMPARISON.md](../COMPARISON.md).
Исполняемые команды одинаковы.

```sh
make avtpak
```

Получаются `build/АВТПАК.lst` при загрузке в **052000**, отдельный
`build/АВТПАК-пакет.lst` для исполнения части образа по **004000** и полный
`build/АВТПАК.dump`. Разметки:
[АВТПАК.sym](../syms/АВТПАК.sym),
[АВТПАК-пакет.sym](../syms/АВТПАК-пакет.sym).
Тип 257 запрещает дизассемблеру продолжать исполнение через данные
и остаточные участки. В частности, слова образа **0221–0477** и
**1415–1777** не включены в установленный граф исполнения модуля.

## Размещение и входы

Основная база **М7 = 052000**, НАБЛ — **М10 = 056000**. Загрузочный
дескриптор НАБЛ **56362 = `0010250000400047`** читает модуль в лист 25.
В текущем дешифраторе обращений к нему нет.

| Вход | Назначение |
|---|---|
| 52010 | Устанавливает М7 и передаёт управление разбору АВТ по 52500 |
| 52011 | ПАКЕТ: читает вторую копию АВТПАК в лист 2, разбирает имя массива |
| 52012 | Возобновляет выборку приказов по 04141 при уже установленной цепочке |
| 04040 | Устанавливает подмену ввода/вывода НАБЛ и преобразует текст цепочки |
| 53015 | Возврат с ошибкой трансляции |
| 53016 | Возврат после успешной трансляции |
| 53024 | Сообщение Э74 во время счёта |
| 53032 | Сообщение об ошибке во время счёта |

Копия в листе 2 нужна для ПАКЕТ: адреса **04040–04210** в ней абсолютные.
Вход 52011 читает её через **52034 = `0010020000400047`**. Если указан
массив, **52021–52025** загружают его и задают возврат: восстановить НАБЛ
с барабана 27:037 и перейти на 056010. Без имени используется текст
из памяти 010000 и исходный нулевой адрес возврата.

Есть также вход из первоначального ПУСК: **00624–00627** читают 40:047
в лист 2 и переходят на **04040**, если флаг 00055 ненулевой.
Это сохранённый путь первоначального пакетного запуска.

## АВТ: аргументы и режимы

Синтаксис и примеры приведены в [§ 19 руководства пользователя](PULT-User.md#pdf-032):

```text
АВТ ИМЯ
АВТ БУФ(ЗЛ А)
АВТ (СЛ)
АВТ ИСПР(СЛЗЛ ПК)
АВТ ЦЕЛЬ(Т=М1 ВЫХ НАЧ)
```

**52500–52504** сохраняют имя текущего архива из 57770 и очищают рабочие
слова 53121–53143, включая два массива по восемь имён. Разбор использует
процедуры НАБЛ **57700** (имя с пробелами справа) и **56245** (следующая
лексема). Возврат этих процедур имеет варианты по М11 и 1(М11).

**52505–52540** различают имя массива, начало списка `(` и разделители.
Пустое окончание 0377 без аргументов попадает в общий путь ошибки
синтаксиса **52532–52533 → 56077**. Явного сообщения АВТПАК этот путь
не печатает.

| Режим | Проверка | Изменение состояния |
|---|---|---|
| ЗЛ | 52541–52543 | Добавляет к заголовку `0x000000010000` |
| СЛ | 52544–52550 | Добавляет `0x000000020000`, увеличивает флаг источника |
| СЛЗЛ | 52551–52554 | Добавляет `0x000000030000`, увеличивает флаг источника |
| Т | 52561–52607 | Запрещает автоматический счёт, принимает до восьми имён после `=` |
| А | 52614–52616 | Запрещает счёт, снимает исходный режим вывода без специального указателя |
| О | 52617–52622 | Как А, дополнительно включает заголовок прокрутки |
| ПК | 52623–52627 | Как А, добавляет `0x000000000600` к заголовку |

Флаг только трансляции — **53146**; исходный режим вывода — **53144**;
флаг наличия имени — **53150**. Отдельное слово **53143** управляет
подготовкой источника: значение 2 выбирает короткую ветвь без копирования
исходного текста из 010000. Это соответствует СЛ/СЛЗЛ без массива
исправлений. Прочие варианты копируют текущий или загруженный текст.

**52610–52613** убирают начальные пробелы у имён меток. Восемь имён
хранятся в **53123–53132**, их варианты для ИТМ — в **53133–53142**.

## Поиск исходного массива

Локальная процедура **53275 → 53302** получает имя массива в 53277,
контрольное имя архива в 53276 и адрес загрузки в 53300. Для АВТ это
010000; для ПАКЕТ действует то же исходное значение.

Она использует ту же пару каталогов, что и резидентный загрузчик:

1. **53302–53304** получают дескриптор архива из НАБЛ 57776, добавляют
   адрес листа 3 и меняют М10 на базу самого АВТПАК.
2. Имя **БУФ** в **53305–53316** обрабатывается отдельно: читаются
   11 зон барабана 27, дорожки 000–012, в последовательные листы
   начиная с листа 4. Конечный адрес отмечается как 035777.
3. **53317–53327** читают каталог с барабана 27:036 в 06000. При
   несовпадении контрольного имени перечитывают его с МЛ и сохраняют
   на барабане. Повторное несовпадение готовит сообщение «СТОИТ…МЛ…».
4. **53330–53340** ищут имя в парах каталога до границы из 06377.
   Неудача готовит сообщение «НА МЛ … НЕТ ЗАДАЧИ С ИМЕНЕМ …».
5. **53341–53361** извлекают начало и длину массива, читают его зоны
   в последовательные листы и возвращают успех через **1(М11)**.
   Ошибка возвращается по **(М11)** с адресом сообщения в М1.

Слова **53300–53301** хранят начало и последний адрес загруженного
массива. Для АВТ это важно и при формировании исходного текста.

## Загрузка и запуск старого транслятора

**52644–52647** последовательно выполняют четыре Э70:

| Слово дескриптора | Обмен |
|---|---|
| 53115 | 40:071 → 00000–01777 |
| 53116 | 40:072 → 02000–03777 |
| 53117 | 40:073 → 04000–05777 |
| 53120 | 40:074 → 06000–07777 |

Проверки сигнатуры транслятора здесь нет. Адреса последующих исправлений
жёстко привязаны к его старой версии.

**52650–52702** формируют шестибайтный поток ИТМ начиная с **06777**.
По руководству заголовок включает Л00, Л10, Л20 или Л30 для обычного
режима, ЗЛ, СЛ или СЛЗЛ. Код объединяет выбранные биты с константой
**53175 = `0x0000C9000026`**, добавляет начальный код при исходном
режиме вывода и отдельный заголовок при О.

**52703–52726** читают исходные байты из 010000. Окончание — соседние
байты **063, 0140**. Первый байт 063 переносится; завершение цикла
происходит, если следующий равен 0140, который затем также добавляется.
При флаге источника 2 сразу выдаётся 0140. Последний адрес подготовленного
текста записывается в **00003**.

**52751–53001** переводят имена между GOST и ИТМ. Таблица ИТМ находится
в **53200–53211**, GOST — в **53212–53223**. Подпрограмма перебирает
байтовые позиции слов таблицы и собирает шестибайтное имя сдвигами на
8 бит. Внутренние команды поиска **52766/52774** заменяются через Э75
при выборе направления перекодировки.

Перед входом в транслятор **53002–53013** устанавливают возвраты:

- в **04004** и **04116** помещается `уиа 52000(М7); пб 1015(М7)`;
  это возврат с сообщением об ошибке трансляции;
- в **04533** — тот же шаблон с целью **53016**, успешное окончание;
- для некоторых режимов первая пара исправлений пропускается;
- М15 обнуляется, A получает адрес из 00003; выполняется **пб 00010**.

## Результаты трансляции и счёт

**53015–53023** печатают диагностику из области **07000–077772**
через НАБЛ и возвращаются в цикл приказов. Адрес начала задаётся в 56405,
конец — в 56410. Текст периода заранее установлен в «ТРАНСЛЯЦИИ».

На успешном пути **53035–53044** формируют «НАЧАЛО …:» из адреса,
сохранённого транслятором в **00160**. **53045–53073** перебирают
запрошенные метки, ищут пары (имя, значение) в **010000–051777**
и печатают адрес либо «НЕТ МЕТКИ …».

**53074–53114** выбирают дальнейшее действие:

- если указан режим печати, переходят в НАБЛ через программку,
  которую ожидают по адресу **00001**;
- при запросе меток готовят таблицу для отладчика по **047400**:
  заголовок и 63 пары, преобразуя имена ИТМ в GOST;
- при автоматическом счёте устанавливают М3 = **056010**, М1 = **−036**
  и переходят на **00001**: рабочий запуск и возвраты зависят от кода,
  оставленного старым транслятором в нулевом листе.

Отдельные входы **53024** и **53032** готовят сообщение «Э74» либо
«ОШИБКА В ПЕРИОД СЧЕТА» и передают его форматтеру НАБЛ.
Точная организация ожидаемой программки по 00001 и всех перехватов
счёта требует соответствующего четырёхзонного образа транслятора.

## ПАКЕТ: подмена ввода НАБЛ

**04040** восстанавливает НАБЛ из барабана 27:037 в 056000. При
ненулевом адресе возврата 04037 сохраняет этот образ также на 27:032.
Через Э75 исходные команды по адресам, упакованным в **56416–56417**,
разворачиваются с учётом базы М10. Затем в точки вызова устанавливаются:

| Точка НАБЛ | Новые команды |
|---|---|
| Из 56416 | `э70 404(М10); пб 04134`, печать строки |
| Из 56417 | `э70 404(М10); пб 04141`, получение строки |
| 56404 | Чтение листа 2 из барабана **27:034** |

Первая подмена зависит от флагов **04035/04037**. В текущем НАБЛ эти
точки — **56424** и **56540**: **56416 = `4300042400000000`**,
**56417 = `4300054000000000`**. После сдвига на 24 бита прежняя
команда оказывается в младшем полуслове; её младший адрес используется
как смещение новой пары команд от базы М10.

**04103–04126** преобразуют текст из **010000–010776** в список
по адресу **05000**. Разделитель записей — целое слово из шести
пробелов GOST, **04132 = `0x0F0F0F0F0F0F`**; конец — слово из шести
восклицательных знаков, **04133 = `0x5B5B5B5B5B5B`**.
Пустая запись также завершает выборку.

Перед каждой строкой оставляется управляющее слово:

```text
старшие 24 бита = отрицательная длина текста в словах
младшие 24 бита = адрес следующего управляющего слова
```

После текста добавляется ограничитель **04216 = `0x7D7AFFFFFFFF`**.
Список вместе с копией кода сохраняется из листа 2 на барабан 27:034;
изменённый НАБЛ — на 27:037. Работа продолжается по **056010**.

**04141–04201** находят очередную непустую запись, обнуляют её счётчик,
переносят текст в буфер, указанный **56406**, и записывают отрицательное
число перенесённых слов в **56411**. В конце буфера ставят слово из
единиц. Состояние списка снова сохраняют на 27:034; возврат идёт через
М11. Вариант вызова для печати может использовать другой адрес буфера
из М15; отдельная процедура **04134–04136** печатает через Э64.

При исчерпании цепочки **04202–04210** завершают задачу через Э62 0
либо восстанавливают НАБЛ с 27:032, записывают его на 27:037, выполняют
заданный обмен из 04036 и возвращаются по адресу 04037.

### Преемник ПАКЕТ в руководстве

[§§ 15–16 руководства пользователя](PULT-User.md#pdf-027) описывают
**EX (EXECUTE)**: выполнение цепочки из архивного массива с разделителем
приказов 0175, подстановкой параметров `"1`, `"2` и т.д., рекурсией
и анализом результата предыдущего приказа. `"0` может получать номер
строки, найденной приказом С. ДАЙ СТОП задаёт реакцию на неуспех;
ДАЙ ТТ/ТТН и ПП/ППН управляют протоколом цепочки.

В историческом каталоге **EX — отдельный модуль 025/001**. Он
выполняет роль расширенного исполнителя цепочек. Исторический каталог
перечисляет одновременно EX и АВТПАК, поэтому сам по себе не датирует
замену одного механизма другим. На исследуемых
томах отдельного имени EX в каталоге и входа в таблицах команд нет;
наличие его кода внутри резервных областей пока не установлено.
**ВПАК** в § 17 описан как подготовка отдельной пакетной задачи из
цепочки, после которой выполняется ДИСПАК БУФ. Такое описание нельзя
автоматически переносить на одноимённый режим текущего СТАТИС.

## Проверки на частных томах

Динамические пробы выполнены последовательно в dispak вне песочницы,
с отдельным HOME и временными копиями томов 2248/2068. Исходные образы
и генератор 2068 не исправлялись. Для входа в сохранившийся код в пробах
временно заменены две записи таблицы НАБЛ и два неиспользуемых перехода:
чтение по дескриптору 56362, затем переход на 52007 для АВТ либо
52011 для ПАКЕТ. Слово **52007** содержит совместимый с Э70 дескриптор,
а при исполнении — `сч 2700; рж 37`, после которого следует вход 52010.
Теги изменяемых слов на частной копии сохранены.

| Проба | Наблюдение |
|---|---|
| Штатные АВТ и ПАКЕТ | Оба имени уходят в архивный поиск, АВТПАК не загружается |
| Временный АВТ без аргументов | Отказ по разделителю 0377, возврат в НАБЛ |
| АВТ XYZ без настройки архива | Локальный поиск исходника, диагностика «СТОИТ…МЛ…» |
| АВТ (Т), нулевой исходный буфер | Чтение 40:071–074; затем цикл поиска окончания текста, остановлен тайм-аутом |
| АВТ (Т), только байты 063,0140 в 010000 | Формирование потока, исправления 04004/04116/04533, переход на 00010; исполняется посторонний образ из переиспользованных зон, дважды печатается «О.К», затем возврат в НАБЛ |
| ПАКЕТ с пустым буфером | Установка подмен, завершение через 04203: Э62 0 |
| ПАКЕТ со строкой Я и конечным словом | Строка переносится в 57640; ПУСК 01440 читает ЗГЛВК и выдаёт её через Э64; после исчерпания цепочки выполняется Э62 0 |

В последней пробе возврат из **04201** идёт на **056017**; далее
**056020** вызывает разбор имени, а дешифратор направляет Я в ПУСК
**01440–01446**. Там выполняются чтение ЗГЛВК и **Э64 01451**.
Терминальный `.out` не содержит этой выдачи: её наличие установлено
по трассе Э64. Очистка буфера **057001–057003** происходит уже после
выполнения приказа, в следующем цикле. Простая цепочка ПАКЕТ таким
образом работает с нынешним НАБЛ после временного подключения входа;
полный набор вариантов печати и вложенного возврата не проверен.

Вывод «О.К» в пробе с конечным маркером не подтверждает трансляцию:
вход 00010 уже принадлежит содержимому нынешних зон 071–074. Успешная
трансляция старым автокодом не установлена.
Пробы сохраняются в `build/avtpak-probes/` как `.input`, `.b6`, `.out`
и `.trace`; вспомогательный скрипт — `probe.py` в той же области build.
Штатные тома остаются историческими образами с удалёнными приказами.
