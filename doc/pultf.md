# ПУЛЬТФ: содержимое сохранившегося файла

В [историческом каталоге ПУЛЬТа](PULT.md#pdf-008) ПУЛЬТФ указан
как однозонный **«Модуль генерации пускачей»**, зона **004**.
На томах 2148 и 2248 имя по-прежнему указывает на **01004**,
на восстановленном 2068 — на **004**. Но содержимое этого файла
не даёт действующего генератора пускачей. В нём находятся
служебные обмены, фрагмент разбора автокодового текста и большой
фрагмент спискового интерпретатора с обращениями за пределы образа.

Образы 2148 и 2248 совпадают целиком. SHA-256 шестибайтного образа:
`935a5790b420f87fcf9f2b9f5ba8d5f537bdf8f500ca6c8f88ac4e9e4cae88d2`.
В 2068 он перенесён без исправлений. Восстановленной исправной версии
генератора под этим именем нет. По совпадению двух томов нельзя
датировать изменение содержимого или установить, было ли оно намеренным.

Все адреса и номера устройств/зон ниже восьмеричные. Размеры в словах
и номера томов — десятичные. Маски и отдельные составные значения
представлены шестнадцатерично.

## Листинг и пределы атрибуции

```sh
make launchers
```

Получаются `build/ПУЛЬТФ.lst` и полный `build/ПУЛЬТФ.dump`.
Разметка — [syms/ПУЛЬТФ.sym](../syms/ПУЛЬТФ.sym).
Явно выделены заголовок, дескрипторы, устанавливаемые пути исполнения
и примеры процедур интерпретатора. Остальной код не выдаётся за
восстановленный алгоритм генерации пускача.

В текущих таблицах НАБЛ, ПУСК и БАВТ имени ПУЛЬТФ нет. Приказ
**ПУЛЬТ** загружает другой файл, **40:002**, и выполняет
[генератор из зоны 01002](pult.md). Обращений к 40:004 из этих
диспетчеров при обычном вводе приказов не установлено.

## Заголовок и два пробных входа

**00000–00007** имеют обычный заголовок машинного образа с отметкой
**Р0802** в 00004. По 00006 стоит `пб (М3)`.
Слово 00007 — **`0x000000087006`**:

```text
00007  зп 0; э20 70006
00010  пб 00400
```

Обычный вход БАВТ по 00007 поэтому вызывает Э20. Внутренний переход
00010 ведёт в середину фрагмента разбора текста. Он не начинает
диалог формирования паспорта.

**00400** выполняет `нтж 00260; пе 00221`. Константа 00260 = **063**.
При входе с A, оставшимся от загрузки, выполняется переход на 00221.

**00221–00231** — отдельная служебная процедура переноса 256 слов:

1. Команды РЖ получают значения из слов 00100 и 00200.
2. М1 сохраняется в 00232, затем принимает **−0377**.
3. Цикл переносит **M[М4 + i] → M[010400 + i]**, `i = 0…0377`.
4. М4 становится **010400**, М1 восстанавливается, возврат идёт через М14.

Это процедура с заданным соглашением о регистрах, которое загрузочный
вход БАВТ ей не обеспечивает. В частности, М14 там указывает на область
аргументов БАВТ. Такой запуск не подтверждает работоспособности модуля
даже при успешном чтении самой зоны.

## Служебные обмены

В начале образа сохранились следующие данные:

| Адрес | Содержание |
|---|---|
| 00011 | Текст **БАЗА** |
| 00012 | Чтение **56:0400 → лист 2** |
| 00013 | Чтение **27:000 → лист 2** |
| 00015 | Чтение **27:031 → лист 37** |
| 00023 | Чтение **27:037 → лист 27**, восстановление НАБЛ |
| 00024–00027 | Чтение **40:057–062 → листы 3–6** |

**00016–00022** восстанавливают НАБЛ и СБОЙ, назначают адрес обработки
ошибок через Э50 0103 и возвращаются в НАБЛ по 056010.
Дескрипторы 00024–00027 не образуют загрузки генератора ПУЛЬТ:
на исследуемом архиве они затрагивают конец ЛЕС и ЧИСТКА.

**00150–00161** и **00200–00211** содержат два девятиобменных варианта
сохранения/восстановления контекста. Один вариант пишет участки памяти
на барабан 27, другой читает их обратно; направления для второй
группы дорожек меняются на противоположные:

| Участок | Первая группа дорожек | Вторая группа дорожек |
|---|---|---|
| Части памяти по смещениям М10+1, +2, +3 | 0122, 0222, 0322 | 0120, 0220, 0320 |
| Листы 1 и 2 | 023, 024 | 021 для листа 1 |

Здесь встречаются специальные дескрипторы с установленным старшим
битом и поквартальной адресацией; их нельзя полностью описать как
обычный обмен целого листа. Таблица показывает поля дорожек, без
утверждения, что все варианты таких обменов исполнены в пробе.
**00173–00177** меняют одну из команд обмена через Э75.

Эти фрагменты свидетельствуют о работе с контекстом памяти, но
не устанавливают конкретного приказа, который должен их вызывать.

## Разнородные фрагменты внутри зоны

Слова **00254–00357** — 68 последовательных слов — совпадают
со словами по тем же смещениям в [АВТПАК](avtpak.md). В них есть
константы кодов, упаковка исходных байтов, разбор лексем и переходы
к общим процедурам за пределами этого участка. В **00360** общее
продолжение уже расходится. Это точное побайтовое совпадение части
образов; оно не доказывает вызова АВТПАК из ПУЛЬТФ.

Начиная примерно с **00410** преобладает другой код: типизированные
ссылки, извлечение полуслов, обход цепочек и вызовы интерпретаторных
процедур. Например:

- **00554–00557** организуют вызов процедуры через М5 с сохранением
  продолжения М6 на стеке М17;
- **00704–00755** проверяют вид значения по маскам и константам,
  затем выбирают способ его обработки;
- **01405–01406** извлекают старшее 24-битное полуслово объекта;
- **01407–01464** содержат набор комбинаций переходов по младшим
  ссылкам и извлечения старших полуслов;
- **01475–01622** содержат арифметические операции, режимы РЖА
  и вызовы математических экстракодов.

Такая структура характерна для ЛИСП-подобного спискового интерпретатора.
Это атрибуция по устройству кода: таблица имён операций и полный
соответствующий образ пока не найдены. Названия CAR/CDR конкретным
адресам без таблицы имён не присваиваются.

Многочисленные ссылки на **02140**, **03254–03347**, **04314–04437**,
**05245–05246** и другие адреса лежат за пределами однозонного файла.
Требуемых процедур и констант в нём нет. Паспортной заготовки,
аналогичной ПУЛЬТ, и явного вызова **Э50 7701** в этом образе нет.

## Проверки

Две пробы выполнены в dispak вне песочницы, с отдельным HOME
и временной копией 2068. Для загрузки ПУЛЬТФ в частном БАВТ
дескриптор **67363** временно заменён с **40:002** на **40:004**.
Вторая проба дополнительно меняла переход 66704 на 00010.
Штатные файлы и тома не исправлялись.

| Вход | Результат |
|---|---|
| 00007 | Исполняется `э20 70006`; СБОЙ сообщает **АВОСТ 000030**, затем возвращает управление в НАБЛ |
| 00010 | Переход 00400 → 00221; перенос блока при М4=0; возврат по М14 на 077331; последующее исполнение посторонних слов заканчивается **АВОСТ 000030** по 010405 |

Трассы и ввод сохранены в `build/launchers-probes/form-{7,10}.*`.
Ни одна проба не сформировала задачу. Они проверяют последствия
двух конкретных входов в сохранившийся файл; правильное начальное
окружение неизвестного интерпретатора ими не воспроизводится.

Содержимое ПУЛЬТФ нельзя использовать для восстановления второго
варианта генератора пускачей по одному каталожному описанию.
Обе документированные формы приказа ПУЛЬТ уже реализованы в
работающем модуле из зоны 01002. Первоначальная роль отдельного
ПУЛЬТФ и происхождение его нынешнего составного образа остаются
неустановленными.
