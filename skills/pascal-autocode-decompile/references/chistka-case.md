## Оригинал и компоновка

ЧИСТКА находится в зонах 01060–01062 томов 2248 и 2148; все 3072 слова
этих двух копий совпадают. Дата программы — 10.12.82.
Адрес загрузки 0, вход 00007. Зоны 060–062 тома 2068 соответствуют
этому же месту архива, но при сравнении всегда проверяй фактические байты.

| Часть | Проверенные границы |
|---|---|
| Массив литералов | 00011–00546, 350 слов |
| Начало процедур | 00547 |
| Главная программа | 05122, размер 0121 слово |
| Служебный хвост | 05243–05261 |
| Конец программы / начало кадра | 05262 |
| Выделенный образ | 3 зоны, 3072 слова |

Адреса и размер 0121 здесь восьмеричные; 350 и 3072 — десятичные.

Физический порядок 43 входов процедур:

```text
00547 00641 00657 00675 00721 00730 00761 01000 01014 01034 01053
01071 01442 01512 01563 01604 01644 01665 01714 01762 01773 02017
02057 02151 02172 02223 02310 02576 02701 02733 03160 03224 03350
03472 03644 03723 03761 04213 04431 04516 04744 04756 04764
```

L1034 и L1053 вложены в L1071, но физически располагаются перед её телом.
Не потеряй эти два участка при подсчёте размеров.

## Подтверждённые решения восстановления

### Типы

Восстановление BOOLEAN у результатов L1000, L1034, L1773, L3160,
у ряда локальных флагов и третьего аргумента L4516 вернуло соответствующие
логические проверки. L2172 при этом остаётся целочисленной функцией.

Запись имени — шесть слов: ALFA, BOOLEAN, три INTEGER, указатель.
Запись блока — шестнадцать слов: ALFA, три BOOLEAN, три INTEGER,
три указателя на блоки и шесть списков имён. Эти размеры подтверждены
NEW, смещениями полей и разными потребителями записей.

### Литералы

В глобальном CONST последовательно объявлены значения 00014–00074.
Удаление 98 объявлений C00075–C00236 не изменило ни одного слова образа:
эти литералы компилятор создаёт из описаний типов и использований
в нужном порядке.
31 оставшаяся текстовая константа объявлена строковым литералом
с именем по содержимому (`Spaces`, `KwBegin`, `OpSCh` и другие).
Замена 48 употреблений строк этими именами не изменила машинный образ.
Шесть пробелов `Spaces` дают слово `0F0F0F0F0F0F` в ГОСТ.
Служебные литералы 00011–00013 создаёт компилятор; строки WRITE/BIND
и локальный дескриптор InputReadZone в BindInput (04744) дополняют массив до 00546.

Порядок повторных строк сохраняется. Переход на общий строковый CONST
не был бы автоматически эквивалентен по размещению. После объединения
WRITE с несколькими аргументами весь массив остался тем же.

### Ветвления и точная форма операций

- L1512 использует CASE по шести видам объявлений.
- L1563 проверяет принадлежность `digit`; реальные суффиксы чисел — Т, С, В.
- L1604 сохраняет порядок записи символа, GET и увеличения индекса.
- L1014 сохраняет явный ELSE после EXIT: он соответствует генерации
  оригинала, включая недостижимый переход.
- Пустые проверки в L3224/L3350 и самоприсваивание в L2733 отражают
  исходные команды; их удаление нарушало бы сверку.
- L2733 и L3644 замыкают циклы через символический CODE с явным концом
  слова. Это объясняет расположение возврата без добавления фиктивного EXIT.
- L4744 использует A после присваивания базы дескриптора; лишняя загрузка
  базы перед CODE меняла бы команды.
- В L4764 переменная адреса используется также в начальном цикле
  пропуска трёх символов. Отдельный придуманный индекс менял бы кадр.
- Директива `k20` задаёт 20 страниц динамической памяти: перед CL
  в М12 загружается 050000. Без неё компилятор резервирует четыре
  страницы (010000), меняя слово 05123. Размер задаётся как K × 1024 слов.
- Финальный разбор Х/Х1 в L4764 задаёт BOOLEAN непосредственно из сравнений;
  порядок присваиваний проверен по оригиналу.

### Подтверждённые сокращения исходника

Для ЧИСТКИ проверено полное равенство машинных слов до и после:

- Снятия лишних скобок, перевода небольших C-констант в десятичную
  запись и объединения WRITE/WRITELN.
- Замены 30 конструкций «метка; IF; тело; GOTO метка» на WHILE,
  с сохранением оставшихся входящих ссылок.
- Объединения 14 групп соседних WRITE/WRITELN с устранением 25 вызовов
  на уровне записи исходника. Сгенерированные операции вывода сохранились.
- Объединения 38 пар вложенных IF через AND с сохранением ELSE.
  Повторный анализ обратных переходов выявил ещё пять WHILE:
  по меткам 0661, 1717, 2252, 2400 и 5200.

Эти количества описывают конкретную работу и не задают требований
для другой программы. Повторно проверяй генерацию после новых изменений.

## Воспроизводимая проверка

Запускай из корня `re-pult`, последовательно:

```sh
python3 tests/rebuild-analyzers.py --program chistka --dispak /home/leob/git/dispak/build/dispak/dispak
```

Сценарий использует частные тома и целый майский компилятор Паскаль 9
от 17.05.88 из 2248:01101–01114. Историческая привязка автокода ИТМ
обеспечивается паспортом и подключением устройства 57; не выводи её
из номера тома без проверки карты и смещения. Параметр `--725` нужен
в этой конфигурации. Не заменяй рабочий том по ходу проверки.

Сценарий проверяет компиляцию, весь массив литералов, входы и размеры
43 процедур, main и служебный хвост, затем 20 функциональных случаев.
Сравниваются все слова трёх выделенных зон, включая заголовок и остаток.

Для проверки только поведения уже скомпилированного образа:

```sh
python3 tests/chistka.py --image build/chistka-rebuild/generated.bin --dispak /home/leob/git/dispak/build/dispak/dispak
```

Артефакты пересборки:

```text
build/chistka-rebuild/compile.input
build/chistka-rebuild/compile.out
build/chistka-rebuild/compile.trace
build/chistka-rebuild/original.bin
build/chistka-rebuild/generated.bin
build/chistka-rebuild/comparison.json
build/chistka-rebuilt-check/
```

В JSON поля `routine_layout` и `literal_pool` проверяются отдельно
от `exact_match` и `differing_addresses`.

Строгое сравнение:

```sh
python3 tests/rebuild-analyzers.py --program chistka --exact --dispak /home/leob/git/dispak/build/dispak/dispak
```

При описанном состоянии оно завершается ошибкой: **140 слов различаются**,
несмотря на совпадение всех размеров, адресов входов и литералов.
Оставшиеся различия включают дату (одно слово) и входы АДСИС (139 слов);
полную причину каждого слова определяй по свежему отчёту.

Не объявляй ЧИСТКУ побитово восстановленной. СЕРВИС — отдельный пример,
для которого достигнуто полное совпадение всех 3072 слов с заданной
датой среды; ЭХОЛОТ пока представляет частичную структурную реконструкцию.
Для проверки этих сведений читай `doc/servic.md` и `doc/analyzers-source.md`.
